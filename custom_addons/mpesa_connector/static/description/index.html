M-Pesa Connector Core

Reusable Daraja 2.0 API Kernel for Odoo Developers

Provides mpesa.api.mixin — an abstract model exposing all Daraja 2.0 endpoints. Inherit this mixin in any module to add M-Pesa capabilities without duplicating API logic.

class MyModel(models.Model):
    _inherit = ['mpesa.api.mixin']

    def pay(self):
        token = self._get_access_token(key, secret)
        self._stk_push(token, shortcode, passkey, phone, amount, url, ref)
