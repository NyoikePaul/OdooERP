Kenya Legal Compliance

Every regulation.
Built in, not bolted on.

🏛
KRA Monthly Rental Income (MRI) Tax
Finance Act 2025 — effective April 2025
Auto-populate monthly returns from paid invoices. Residential: 7.5% flat. Commercial: 30%. 5-day filing reminder cron. Filed → Paid tracking.
📋
Withholding Tax (WHT)
Income Tax Act — Section 35 KITA
5% residential / 10% commercial auto-computed on every lease. Deducted from landlord payout. Shown separately on invoices.
⚖
Tenancy Agreement & Eviction
Cap 301 — Landlord & Tenant Act
PDF tenancy agreement template. Formal demand notice: 7-day → 30-day → court. All steps logged with witness records and timestamps.
📱
M-Pesa Daraja 2.0
Safaricom API — OAuth2 certified
OAuth2 token caching. Phone normalisation: 07xx / 2547xx / +2547xx all handled. STK Push + C2B + B2C. Full sandbox/production switch.
Quick Start

Up and running
in 60 seconds.

bash — deploy OdooERP Kenya
# 1. Clone and configure
git clone https://github.com/NyoikePaul/OdooERP.git
cd OdooERP && cp .env.example .env

# 2. Add your Daraja credentials to .env
MPESA_CONSUMER_KEY=your_key
MPESA_CONSUMER_SECRET=your_secret

# 3. Start Docker
docker compose up -d

# 4. Install Kenya modules
docker exec odooerp-web odoo -i estate_core,estate_rental,
    estate_sales,estate_finance,kenya_real_estate,
    mpesa_connector,kenya_mpesa_acquirer
    -d odoo --stop-after-init

# 5. Open http://localhost:8069 → login admin/admin
