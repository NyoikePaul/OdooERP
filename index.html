// Core Capabilities

Everything Kenya needs in one ERP

Purpose-built Odoo modules for the East African market — compliant, integrated, and production-ready out of the box.

01 📱

M-Pesa Daraja 2.0 Engine

Full-scale asynchronous STK Push, C2B paybill/till listening, and B2C enterprise payouts. Implements secure Redis-backed token caching, exponential backoff retry policies, payload idempotency keys, and automated split-journal account reconciliation.

02 🏭

B2B Supply Chain & Distribution

Automated multi-warehouse route workflows, custom certified dispatch weighbridge telemetry logging, landed-cost calculators, bulk merchant pricing matrices, and automated delivery order creation from high-throughput sales endpoints.

03 🇰🇪

KRA eTIMS OSCU Integration

Client architecture natively integrated into Odoo account workflows for real-time invoice payload transmission. Validates merchant KRA PIN parameters, calculates complex multi-tier Withholding Tax schedules, and registers OSCU signatures locally without specialized hardware.

04 📊

Automated Financial Reconciliation

Automated cron engines matching incoming M-Pesa transaction reference patterns against outstanding bulk commercial invoices, automatically computing transaction fees directly to allocated operational cost-centers.

05 🐳

Production DevOps Infrastructure

Hardened, enterprise-grade docker-compose.prod.yml setups containing isolated app servers, a decoupled PostgreSQL 16 state engine, optimized Nginx reverse proxy routing, auto-renewing Let’s Encrypt TLS hooks, and zero-downtime automated target server backup crons.

06 🛡️

Strict Enterprise Hardening

Continuous static analysis integration using Bandit security scanners, isolated server environment secrets configuration, deterministic role-based ACL matrix setups, and immutable transaction audit logs capturing comprehensive raw webhook metadata.
