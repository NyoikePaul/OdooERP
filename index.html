// Core Capabilities

Everything Kenya
needs in one ERP

Purpose-built Odoo modules for the East African market — compliant, integrated, and production-ready out of the box.

01
📱
M-Pesa Daraja 2.0
Full STK Push, C2B paybill/till, B2C payouts. Token caching, exponential retry, phone formatting, automatic reconciliation. Works with Sales, POS, eCommerce.
02
🏠
Real Estate CRM
Property listings with Kanban view, tenant lease management, PDF tenancy agreements (Kenya Landlord & Tenant Act), bulk rent invoice wizard, maintenance tracking.
03
🇰🇪
Kenya Localization
KRA PIN validation, VAT 16%, Withholding Tax schedules, KRA eTIMS OSCU real-time invoice submission. No eTIMS hardware needed. Chart of accounts aligned to Kenya.
04
🔧
Maintenance Module
Property maintenance requests with priority stars, category tracking (plumbing, electrical, structural), cost tracking, assigned technician, full chatter history.
05
🐳
Production Docker
Hardened docker-compose v2 (dev + prod), Nginx reverse proxy, Let's Encrypt SSL, one-command backup. Deploy to any Ubuntu server in under 5 minutes.
06
🛡️
Enterprise Security
Bandit security scanning in CI, Dependabot auto-updates, env-based secrets, role-based access, transaction audit log with full raw payload storage.
