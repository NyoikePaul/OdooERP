// East Africa Pain Points We Solve

Built from
real problems.

Not a generic real estate module with Kenya flag added. Every feature was designed for a specific East African market failure.

01
💸
Manual Rent Collection
53% of Kenya landlords still use WhatsApp, cash, and Excel. Chasing tenants is the #1 complaint.
→ M-Pesa STK Push auto-reconciled to invoices. Tenant receives phone prompt.
02
🏛️
KRA MRI Compliance (2025)
KRA launched new Monthly Rental Income system April 2025. Most landlords don't know how to comply.
→ Auto-populate returns from invoices. Tax due calculated. 7.5% / 30% rates applied.
03
⚡
Generator Cost Disputes
Every building has a standby generator. Fuel costs split among tenants is a constant dispute.
→ Log hours run → auto-calculate fuel cost → apportion by unit → generate invoices.
04
📋
No Tenant Vetting Process
Kenya has no formal credit bureau. Bad tenants are onboarded due to lack of screening tools.
→ Scoring engine: ID + payslips + employment + income ratio + previous landlord ref.
05
⚖️
Eviction Process Confusion
Landlord & Tenant Act (Cap 301) + BPRT for commercial. Most landlords skip steps and face court loss.
→ Formal demand notice workflow → 7-day/30-day → BPRT escalation → court summons.
06
💧
Service Charge Disputes
Security, cleaning, borehole, compound lighting costs shared among tenants — manual calculations cause disputes.
→ Apportion by equal split / unit sqft / bedrooms. Auto-generate invoices per unit.

// Kenya Legal Compliance

Every regulation.
Built in.

Not an afterthought. Compliance is core business logic — auto-computed, tracked, and reported.

🏛️ KRA — April 2025
Monthly Rental Income (MRI) Tax
Auto-populate returns from paid invoices. Residential: 7.5% flat (income < KES 288k/mo). 5-day filing reminder cron. Track filed → paid status.
📋 Income Tax Act — Section 35 KITA
Withholding Tax (WHT)
5% residential / 10% commercial auto-computed on every lease. Deducted from landlord payout. Shown separately on invoices.
⚖️ Cap 301 — Landlord & Tenant Act
Tenancy Agreement & Eviction
PDF tenancy agreement template. Formal demand notice workflow: 7-day → 30-day → court. All steps logged with witness records.
🏢 Business Premises Rent Tribunal
Commercial Rent Disputes (BPRT)
Commercial lease escalation requires BPRT notice. Workflow flags commercial leases and routes demand notices to BPRT filing track.
📱 Safaricom — Daraja 2.0
M-Pesa Integration
OAuth2 token caching. Phone normalization to 2547XXXXXXXX. STK Push + C2B paybill + B2C payouts. Full sandbox/production switch.
👷 Employment Act — NHIF/NSSF
Caretaker Employment
Caretaker records store NHIF, NSSF, KRA PIN numbers. Monthly salary + house allowance auto-generates vendor bills for payroll.
// Quick Start

Up in 60 seconds.

Docker Compose handles everything. One command to start, one to install modules.

# 1. Clone & configure
git clone https://github.com/NyoikePaul/OdooERP.git
cd OdooERP && cp .env.example .env

# 2. Add your M-Pesa Daraja credentials to .env
MPESA_CONSUMER_KEY=your_key
MPESA_CONSUMER_SECRET=your_secret

# 3. Start Docker
docker compose up -d

# 4. Install modules
docker compose run --rm web odoo \
  -d odoo_kenya -i mpesa_connector,mpesa_integration,kenya_mpesa_acquirer,kenya_real_estate \
  --stop-after-init --no-http

# 5. Open http://localhost:8069 → login admin/admin
